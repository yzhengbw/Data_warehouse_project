# Data Catalog

## Overview

This data catalog documents the datasets and warehouse objects used in the SQL Data Warehouse project. The solution ingests data from two source systems, stores it in a three-layer Medallion architecture, and exposes a star-schema model for analytical consumption.

- Source systems: CRM and ERP
- Layers: Bronze, Silver, Gold
- Data format: CSV files ingested into SQL Server tables/views
- Modeling pattern: Star schema with dimension and fact objects

---

## Gold Layer

The Gold layer contains the final analytical objects in star-schema form. The project creates views for dimensions and facts:

### Customer Dimension

View: `gold.dim_customer`  
provides the customer profile

| Column | Description |
|---|---|
| `customer_key` | Surrogate key generated by `ROW_NUMBER()` |
| `customer_id` | Customer ID from CRM |
| `customer_number` | Business identifier for customer |
| `firstname` | Customer first name |
| `lastname` | Customer last name |
| `marital_status` | Customer marital status |
| `birthdate` | Birth date from ERP |
| `gender` | Preferred gender, prioritizing CRM when available |
| `country` | Country mapped from ERP location data |


### Product Dimension

View: `gold.dim_product`  
provides the product information

| Column | Description |
|---|---|
| `product_key` | Surrogate key generated by `ROW_NUMBER()` |
| `product_id` | Product ID |
| `product_number` | Product business key |
| `product_name` | Product name |
| `product_cost` | Product cost |
| `product_line` | Product line |
| `start_date` | Product start date |
| `category_id` | ERP category ID |
| `category` | Product main category |
| `sub_category` | Product subcategory |
| `maintenance` | Maintenance flag |


### Sales Fact

View: `gold.fact_sales`  
stores latest transactional events

| Column | Description |
|---|---|
| `order_number` | Sales order number |
| `product_key` | Foreign key to `gold.dim_product` |
| `customer_key` | Foreign key to `gold.dim_customer` |
| `order_date` | Order date |
| `ship_date` | Shipment date |
| `due_date` | Due date |
| `sales` | Revenue or sales amount |
| `quantity` | Quantity sold |
| `price` | Unit price |
